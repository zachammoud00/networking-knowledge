# Networking Knowledge

## About

This repository serves as a personal knowledge base for my broader network engineering studies. It covers protocol fundamentals and behaviour, practical labs with network topologies, and detailed walkthroughs of packet captures generated in my lab environment.

The goal is to develop a deeper understanding of how network protocols operate, how they interact, and how to analyse and troubleshoot network behaviour in practice.
